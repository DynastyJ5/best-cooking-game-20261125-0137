Copper Ladle Kitchen — a cozy rush-hour cooking game. Grab ingredients from the counter bins, chop them on the board, cook them on the stove, plate the dish and serve it at the window before the order's patience runs out. It runs in a desktop browser from plain static files, keyboard and mouse, no network requests.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.
